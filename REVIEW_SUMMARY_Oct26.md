# Top GCCs India tab: October 2026 research and audit review

Workbook: `GCC_List_TopGCCsIndia_reviewed_Oct26.xlsx` (tab "Top GCCs India", plus a new tab "Oct'26 Review Log").

## How to read the updated tab

- Original text is untouched. Every update is appended below it in **dark blue** with the source link(s).
- `[Oct'26 update – correction]` = existing text found wrong or outdated. `[Oct'26 update – addition]` = cell was empty or "not verifiable" and credible information was found.
- `[Oct'26 re-check – existing text could not be independently verified]` = the auditor could not find any credible source for the existing value. Nothing was deleted; confirm these directly before relying on them.
- `[Oct'26 re-check]` in an FTE cell = no credible public headcount exists.
- Trend (col F) and Trend Source (col G) were empty for all rows and are now filled: focus area (Technology / Operations / Finance), then 2-4 dated news bullets, with one URL per bullet in the same order in col G.
- New companies are inserted as new rows at the end of each section, fully in dark blue, with sources.
- The "Oct'26 Review Log" tab lists every cell touched: row, column, action, old text, new text, sources, audit result and the quoted evidence.

## Verification method and its limit

Two independent passes were run: a researcher pass (one agent per batch of six companies plus a completeness agent) and a separate auditor pass that re-searched every proposed change. The review environment could not open web pages directly, so all claims were checked against search-engine indexed page text from the cited URLs. Items the auditor could not reach within budget are labelled `audit: not audited` in the cell. Counts across the 51 original rows (columns B to H, plus trend):

| Outcome | Count |
|---|---|
| Items verified by auditor | 129 |
| Items amended by auditor | 198 |
| Items rejected (unproven, shown as re-check notes) | 11 |
| Items not reached by auditor | 19 |
